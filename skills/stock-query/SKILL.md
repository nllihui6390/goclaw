## 核心能力

- 查询任意A股股票的实时行情（最新价、涨跌幅、最高价、最低价、开盘价、昨收价）
- 查询港股股票行情（支持5位代码，如 00700、09988）
- 支持上海（6xx/9xx）、深圳（0xx/3xx）股票代码
- 支持**股票名称查询**（如：贵州茅台、腾讯控股、宁德时代等）
- 返回成交量和成交额数据（自动格式化）
- 返回总市值、流通市值、市盈率TTM、市净率等基本面数据
- 返回52周最高/最低价
- 支持 JSON 格式输出

## 执行步骤

1. 确认用户要查询的股票代码或名称 {{stock_code}}
2. 如果用户提供的是股票名称（如"贵州茅台"、"腾讯控股"），使用 `--name` 参数查询
3. 如果用户提供的是股票代码，使用 `--code` 参数查询
4. 使用 Python 脚本查询：`python3 scripts/stock_query.py --code={{stock_code}}` 或 `python3 scripts/stock_query.py --name={{stock_name}}`
5. 将返回的数据整理成表格格式展示给用户

## 输入要求

- `stock_code`: 股票代码，A股6位数字，港股5位数字（如 600519, 00700）
- `stock_name`: 股票名称（如 贵州茅台、腾讯控股、宁德时代）
- 支持常用股票名称自动匹配代码（内置50+常见股票名称映射）

## 输出格式

返回股票的实时行情信息，包括：
- 📊 股票名称和代码
- 📈 最新价
- 📉 涨跌幅（百分比）和涨跌额
- 📈 最高价 / 📉 最低价
- 📊 开盘价 / 昨收价
- 📊 成交量 / 成交额
- 📉 振幅 / 换手率
- 🏢 总市值 / 流通市值（A股）
- 📊 市盈率TTM / 市净率（A股）

## 异常处理

- 如果股票代码格式不正确，提示用户输入正确的股票代码
- 如果查询不到数据，提示用户检查股票代码是否正确
- 如果网络请求失败，返回错误信息并建议稍后重试
- 支持股票名称自动纠错和模糊匹配
